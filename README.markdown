# Расчёт (PWA)

Калькулятор + конвертер единиц + финансы. Телефон, планшет, ПК. Работает офлайн. Без сборки и без `eval()`.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите **содержимое** папки (файл `index.html` должен лежать в корне, рядом папки `css`, `js`, `icons`).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Сайт: `https://ВАШ_ЛОГИН.github.io/РЕПОЗИТОРИЙ/` (нужен HTTPS — GitHub Pages его даёт).

## Установка
Android/Chrome и ПК (Chrome, Edge): «Настройки» → «Установить приложение». iPhone/iPad: Safari → «Поделиться» → «На экран Домой».

## Офлайн и экспорт в Excel
Само приложение работает без интернета после первого открытия. Экспорт в `.xlsx` использует библиотеку SheetJS с cdnjs: она скачивается при первом экспорте и кэшируется. Без интернета и без кэша сохранится CSV (открывается в Excel).

## Обновление
Меняйте файлы и увеличивайте `V` в `sw.js` (`raschet-v2` → `raschet-v3`). После обновления перезапустите приложение.

## Файлы
`index.html`, `css/style.css`, `js/engine.js` (вычисления), `js/db.js` (IndexedDB), `js/tools.js` (конвертер, финансы), `js/app.js` (интерфейс), `sw.js`, `manifest.webmanifest`, `icons/*`, `404.html`, `.nojekyll`, `LICENSE`, `ANALYSIS.md`.

## Примечание
Вибрация: Android (Chrome) — Vibration API; iPhone (iOS 17.4+) — через системный переключатель, нужны включённые «Тактильные сигналы» (Настройки → Звуки). Отключается в приложении (иконка вибрации сверху или Настройки → Отклик).
